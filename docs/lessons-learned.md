# Lessons Learned

Living log of things that went wrong or surprisingly right, and the rule they produced.
Generic lessons (not tied to this project) are tagged **[KIT]** and get promoted into the
`project-kickstart` plugin during the retrospective.

| Date | Context (task / conversation) | What happened | Rule / fix adopted | Scope |
|---|---|---|---|---|
| 2026-11-02 | Developer Narrative & Repository Branding Alignment | Labeling an advanced multi-agent orchestrator with verification gates and token optimization as a generic `project-template` obscured its technical value | Name and brand developer repositories around their primary functional paradigm (`SwarmForge` — The Swarm of parallel workers + The Forge of verification gates) | [KIT] |
| 2026-11-02 | Safe Application Rebranding & Configuration Migration (`xmcompanion`, `mackeys-win`) | Renaming an active application risks breaking user autostart entries, sound profiles, shortcuts, and documentation narrative | Provide automatic backwards-compatible fallback when reading `%APPDATA%\<NewApp>` (falling back to legacy `%APPDATA%\<OldApp>`), clean up legacy Run and Uninstall registry keys on setup/uninstall, stage binary aliases, and update all docs, UI text, and setup wizards consistently | [KIT] |
| 2026-11-02 | Win32 Job Objects for Child Process Lifecycle & Orphan Prevention (`ghost-qa`) | Target processes spawned by `Child::spawn` can orphan child processes if the QA orchestrator crashes or is aborted | Assign spawned processes to a Win32 Job Object with `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE` so the OS terminates the entire process tree on handle close | [KIT] |
| 2026-11-02 | UIA Pattern Invoke vs Win32 Mouse Deduplication (`ghost-qa`) | Win32 window callbacks (`WNDPROC`) using `static mut` suffer race conditions under multi-threaded test runners; `IUIAutomationInvokePattern::Invoke` falling through to `PostMessageW` caused duplicate click events | Store telemetry pointers in `GWLP_USERDATA` on `WM_NCCREATE`; return immediately on successful UIA pattern invoke without falling through to Win32 mouse messages | [KIT] |
| 2026-11-02 | GitHub Linguist Language Stats & Template Discoverability | GitHub misclassified the polyglot template as 100% PowerShell because helper orchestration scripts in `scripts/` dominated file byte counts | Add `linguist-vendored` overrides in `.gitattributes` for auxiliary scripts and installers so language statistics accurately reflect polyglot support | [KIT] |
| 2026-11-02 | GitHub Community Health & Explore Ranking | Repositories lacking a `CODE_OF_CONDUCT.md` are capped at 85% health score, depressing discoverability on GitHub Explore | Include standard Contributor Covenant `CODE_OF_CONDUCT.md` to achieve 100% community health and maximum topic visibility | [KIT] |
| 2026-11-02 | PowerShell String Pipeline Short-Circuit with `$ErrorActionPreference = 'Stop'` | Using `Where-Object { $_ -and (Test-Path $_) }` over an array with `$null` items passed `$null` to `Test-Path`, throwing a terminating exception | Use explicit `foreach ($p in $CandidatePaths) { if (-not [string]::IsNullOrWhiteSpace($p) -and (Test-Path $p)) { ... } }` to guarantee safe short-circuiting | [KIT] |
| 2026-11-02 | TOML Root Keys vs Sub-Tables & Serde Deserialization | Omitting optional vectors without `#[serde(default)]` broke config parsing, and adding keys after `[ai]` placed them under the sub-table | Add `#[serde(default)]` to optional config fields in Rust and place top-level root keys (e.g. `goals = []`) before section headers in TOML templates | [KIT] |
| 2026-11-01 | GUI Hooks & System Stability (`mackeys-win`) | Installing a global `WH_KEYBOARD_LL` hook inside a GUI process (`egui`/`winit`) caused Windows hook timeout contention, system-wide keyboard lockups, and PC freezes | Never install `WH_KEYBOARD_LL` inside a GUI process. Global low-level hooks belong exclusively in headless background daemons. In GUI QA tools, pause daemon remapping via IPC (`set_paused(true)`) and read keys in-window | [KIT] |
| 2026-11-01 | Raw Input Verification vs Synthesized QA Events (`mackeys-win`) | QA tool identified keys from post-remap egui/text events and filled scancodes from defaults -> unverifiable remapped keys, false positives, fabricated columns | Hardware verification tools must capture raw pre-remap input (scancode + extended + device) and never synthesise measured fields | [KIT] |
| 2026-11-01 | End-to-End Call Path as Definition of Done (`mackeys-win`) | Milestones marked complete although the input engine was never wired to OS events and claims were overstated | A roadmap item is "done" only when an end-to-end call path from real input/OS event exists — unit-tested library code alone is "engine ready", not "integrated" | [KIT] |
| 2026-11-01 | Dedicated Release Subdirectories (`dist\v<Version>\`) (`mackeys-win`, `xmcompanion`) | Testing local builds was frustrating because users could not locate individual release binaries scattered across root `dist/` | Every release must output to an isolated per-version folder (`dist\v<Version>\`) containing an unzipped, ready-to-run `portable\` directory alongside installers and archives | [KIT] |
| 2026-11-01 | Telemetry Truth vs Statically Mocked Frontend (`xmcompanion`) | Frontend statically initialized `Connected`, `85%` battery, and dummy wire packets without verifying live link on launch, deceiving users into believing disconnected headphones were active | Never statically hardcode positive connection states in client UI; initialize to neutral (`Checking...`, `--%`), query live WinRT/audio status on load and on an active interval (5s) | [KIT] |
| 2026-11-01 | Dual Bluetooth Profiles (Classic vs BLE Swift Pair) (`xmcompanion`) | Sony headphones advertise both `LE_*` (BLE beacon) and Classic Audio. Windows often pairs only the BLE device, causing silent failure, no audio sink, and no RFCOMM | Diagnostic layer must inspect both Classic Bluetooth and BLE; when only BLE beacon is present, surface `BLE Only (Audio Disconnected)` amber badge and guide user to pair the headphone audio icon | [KIT] |
| 2026-11-01 | Tauri v2 Startup Window Display vs System Tray (`xmcompanion`) | In Tauri v2, configuring a tray icon in `app.setup()` defaults the main window to hidden/unmapped; double-clicking started a silent process with HWND `0` that never surfaced | Call `window.show()`, `window.unminimize()`, `window.center()`, and `window.set_focus()` in `app.setup()` and set `"visible": true`, `"center": true`, and `"focus": true` in `tauri.conf.json` | [KIT] |
| 2026-11-01 | VIS-GLYPH-TOFU Detection & Launch Window Size Calibration (`ghost-qa`) | QA tools had blind spots: (1) missing font glyphs / tofu boxes ('\u{FFFD}' and '□') were reported as 0 defects; (2) testing at arbitrary window sizes missed clipping occurring at the real default launch size | (1) Added `VIS-GLYPH-TOFU` deterministic heuristic; (2) Always capture at target default launch window size; (3) Ground hardware claims strictly in raw unmapped events; (4) Pair headless invariant tests with real-browser/wgpu visual screenshot audits | [KIT] |
| 2026-11-01 | Cargo Test Concurrency Parameter | Passing `--test-threads=auto` to standard `cargo test` triggers `invalid digit found in string` | Use `[System.Environment]::ProcessorCount` to supply an integer thread count to `--test-threads` | [KIT] |
| 2026-11-01 | PowerShell 5.1 `ConvertFrom-Json -AsHashtable` Trap | Using `-AsHashtable` with `ConvertFrom-Json` throws `NamedParameterNotFound` on Windows PowerShell 5.1 (introduced in PS 6+) | Parse as `PSCustomObject` and iterate `.psobject.properties` to ensure universal compatibility across PS 5.1 and pwsh 7+ | [KIT] |
| 2026-11-01 | PowerShell Double-Quote Markdown Backtick Escapes | Escaping markdown backticks (\`code\`) inside PowerShell double-quoted strings treats backticks as escape characters, corrupting quotation boundaries | Format output via single-quoted strings or clean string arrays without nested backtick escapes | [KIT] |
| 2026-11-01 | Dynamic Model Optimization & Token Minimization | Worker subagents defaulting to heavy models exhaust rate limits and user token budgets unnecessarily | Run automated model optimization (`collect-model-stats.ps1` + `apply-model-optimisation.ps1`) to empirically route workers to lightweight models (`flash_lite`) while maintaining >=95% pass rates | [KIT] |
| 2026-11-01 | Task Parallelization & Worktree Isolation | Running parallel tasks or reviewing Copilot PRs in the primary workspace caused branch churn and build invalidation | Use isolated sibling git worktrees (`.worktrees/task-<id>` via `scripts/manage-worktree.ps1`) for concurrent worker execution | [KIT] |
| 2026-11-01 | Verification Gate Latency & Run Optimization | Running full clean builds and all test suites on every minor worker task created excessive waiting latency | Implement a Tiered Verification Gate (`scripts/verify-gate.ps1` with `-Mode Fast` for workers and `-Mode Full` for Sole Committer) | [KIT] |
| 2026-11-01 | Antigravity Skill Scoping & Token Economics | Global skills in `~/.gemini/config/skills/` load in every session and exhaust the 20,000 token budget | Default all skills to workspace scope (`.agents/skills/` - 0 global tokens); use `scripts/manage-skill.ps1` to promote only cross-project utilities globally | [KIT] |
| 2026-11-01 | PowerShell 5.1 Script Encoding & Emojis | Multi-byte UTF-8 emojis in `.ps1` files parsed as ANSI apostrophes in Windows PowerShell 5.1, breaking string termination | Use clean ASCII markers (`[OK]`, `[LOCAL]`, `[GLOBAL]`) in PowerShell automation scripts instead of multi-byte Unicode emojis | [KIT] |
| 2026-10-31 | packaging & release | Releasing multiple executables in distribution bundles confused users and complicated shortcuts | Distribute a single standalone setup executable (`<AppName>-Setup.exe`) and a clean single-binary portable zip | [KIT] |
| 2026-10-31 | UX & In-App Maintenance | Users had no way inside GUI applications to re-run setup, create shortcuts, or trigger uninstallation | Provide in-app maintenance controls (shortcuts, repair, uninstall) and progressive 5-step Setup Wizard | [KIT] |
| 2026-10-27 | Autonomous UI & A11y QA (`ui-qa-tester`) | Embedded web renderers (WebView2/Chromium) delay UIA tree hydration and ignore input messages sent to top-level frames | Walk child HWND trees (depth $\ge$ 15), warm up UIA with a brief 300ms pause, convert coordinates via `ScreenToClient(render_hwnd)`, and calculate contrast on small labels | [KIT] |
| 2026-10-27 | Live QA on Native GUIs (`eframe`/`egui`) | Calling `IUIAutomationElement::GetCurrentPattern` on structural/container elements triggered 2-second MSAA proxy timeouts | Filter `GetCurrentPattern` queries by interactive `UIA_ControlType` IDs, reducing walk latency from ~2,000ms to <15ms | [KIT] |
| 2026-10-27 | DWM Window Bounds Calibration | Windows 11 drop shadow margins (~8px) skew `GetWindowRect` offsets relative to visible client content | Call `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)` to extract true visible window bounds, falling back to `GetWindowRect` | [KIT] |
| 2026-10-27 | Web/Frontend Component Architecture | Single-page views overgrown to 2,500+ lines caused hydration latency and cognitive overload for agents | Decompose page into dedicated tab components (`src/components/tabs/`) and synchronize active tab/filters with URL search parameters (`?tab=...`) | [KIT] |
| 2026-10-25 | Documentation Parity for Multi-Channel Distribution | After adding WinGet/Scoop manifests and setup scripts, documentation still pointed to raw source build directories | Whenever adding or modifying distribution channels, synchronize `README.md`, `docs/user-guide.md`, and `docs/release-methodology.md` in the same commit | [KIT] |
| 2026-10-25 | PowerShell External CLI UTF-8 Encoding | External CLI stdout capture (`gh`, `git`) on Windows PowerShell mangled non-ASCII Unicode characters | Set `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8` and force UTF-8 without BOM before capturing CLI output | [KIT] |
| 2026-10-25 | PowerShell Pipeline Binding Trap | Piping `gh api` output directly into static .NET methods (`[System.Text.Encoding]::UTF8.GetString($input)`) caused PowerShell to hang | Never pipe directly into static .NET methods in PowerShell; use `gh api -H "Accept: application/vnd.github.raw"` or assign to a variable first | [KIT] |
| 2026-10-25 | Windows COM / Win32 RAII Integration | Windows COM interface pointers (e.g. `IMMDeviceEnumerator`) drop after `CoUninitialize()` if in outer scope, causing access violations | Explicitly scope COM objects in an inner block so RAII drops interfaces before `CoUninitialize()`, and free string buffers via `CoTaskMemFree` | [KIT] |
| 2026-10-25 | GitHub Governance & Portable Releases | Binary executables remained only in local ignored build directories without tracked issues or downloadable GitHub Releases | Map every roadmap milestone to a GitHub Milestone and tracked GitHub Issues; attach pre-built `.zip` bundles to GitHub Releases even while hardware QA is `Pending` | [KIT] |
| 2026-10-25 | Multi-Process & Test Concurrency | Automated tests touching global OS resources (pipes, sockets, registry, hooks) collided during parallel test execution | Use unique GUID/timestamp identifiers, isolated thread runners (`--test-threads=1`), and timeout protection to prevent test hangs | [KIT] |
