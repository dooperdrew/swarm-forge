# Skill Scope Guide

This guide explains how to control the visibility of Antigravity skills:

- **Local skills** live under `.agents/skills/` in the repository. They are automatically scoped to the workspace and incur **0 global token cost**.
- **Global skills** are placed in `~/.gemini/config/skills/`. They are loaded in every Antigravity session and consume part of the 20 000‑token customization budget.

## Choosing the Scope

1. **Create a skill** using the scaffolding command:
   ```powershell
   .\scripts\manage-skill.ps1 new MySkill
   ```
   This creates `.agents/skills/MySkill/` ready for local use.

2. **Promote to global** (only when the skill truly needs cross‑repo reuse):
   ```powershell
   .\scripts\manage-skill.ps1 promote MySkill
   ```
   The script copies the skill to the global directory and updates the manifest.

3. **Demote back to local** if you later decide the skill should be repository‑specific:
   ```powershell
   .\scripts\manage-skill.ps1 demote MySkill
   ```

## Token Economics

- Local skills cost **0 tokens** because they are not loaded into the global customization cache.
- Global skills consume tokens proportional to their size; keep them minimal to stay within the 20 000‑token limit.

## Best Practices

- Only promote utilities that are truly shared (e.g., lint helpers, CI scripts).
- Keep UI‑specific or domain‑specific logic local.
- Document any promoted skill in `docs/skill-scope.md` (this file) for future maintainers.
